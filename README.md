# Laura Suttie Personal Website

This is a simple one-page personal website for Laura Suttie. It is built with
plain HTML, CSS, and JavaScript, so it can be published with GitHub Pages.

## Sections

- About
- Building
- Favoriting
- Speaking

## Editing Copy

Most website copy lives in `content.js`.

Use `styles.css` for visual changes like spacing, type, borders, and colors.
Use `index.html` only for page structure changes.

## Preview

Open `index.html` in a browser, or run a local preview server from this folder.

## Publishing With GitHub Pages

Create a GitHub repository and upload every file in this folder:

- `index.html`
- `styles.css`
- `content.js`
- `render.js`
- `laura-photo.jpeg`
- `pin.svg`
- `README.md`

Then in GitHub, go to the repository settings and turn on GitHub Pages from the
`main` branch.

## Custom Domain

This site is configured for:

`laurasuttie.com`

In GitHub Pages settings, use `laurasuttie.com` as the custom domain. At the
domain provider, point the root domain to GitHub Pages and point `www` to:

`lvsuttie.github.io`
